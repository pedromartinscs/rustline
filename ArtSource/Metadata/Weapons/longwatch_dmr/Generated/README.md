# Generated Longwatch metadata

This directory stores versioned metadata derived from authored Longwatch production sprites.

The first generated artifact will be:

```text
longwatch_dmr_muzzle_metadata.json
```

Do not hand-edit generated JSON. Re-run the generator in `Tools/WeaponMetadata/` after relevant source-art changes and review the resulting Git diff.

The generator and schema contract are documented in [`docs/WEAPON_MUZZLE_METADATA.md`](../../../../../docs/WEAPON_MUZZLE_METADATA.md).
